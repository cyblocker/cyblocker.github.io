🔑 钥匙 1：词尾骨架统一律（除 -er 与四大特例外） 单数 -s/-s/-t 读音 100% 相同；全 A1 打破 vous -ez 仅 3 个，打破 ils -ent 仅 4 个
展开
  • 单数 (je / tu / il)：几乎全员 -s, -s, -t 且读音 100% 相同！词干本身以 d / t 结尾时，第3单不重复加 t（如 il vend / prend / met）；仅情态双雄 pouvoir / vouloir 用 -x, -x, -t。
  • 复数 (nous / vous / ils)：骨架永远是 -ons, -ez, -ent（-ent 永远静音不发音）。

🥾 靴子区 (1/2/3单 + 3复) 词尾 -s / -t / -ent 静音不发音 → 重音砸在词干上 → 元音裂变或双写辅音（viens / viennent、bois / boivent、peux / peuvent）。
🧦 靴口外 (nous / vous) 词尾 -ons / -ez 响亮发音抢走重音 → 词干弱化，乖乖跟原形走（venons / venez、buvons / buvez、pouvons / pouvez）。
